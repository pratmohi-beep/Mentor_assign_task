# Java Mentor Tasks

This repository contains three basic Java programs developed as part of my mentor task.

## 1. Basic Calculator (`calculator.java`)
Performs basic arithmetic operations: addition, subtraction, multiplication, and division. Includes input validation and division-by-zero handling.

**Sample Output**
```text
Enter first number: 20
Enter operator (+, -, *, /): +
Enter second number: 10
Result: 30.0
```

## 2. String Validation (`str_validation.java`)
Checks whether a string contains:
- An uppercase letter (A–Z)
- A lowercase letter (a–z)
- A digit (0–9)
- A special character (`#?!@$%^&*-_`)

**Sample Output**
```text
Enter a string: Pratik@123
Valid String!
```

## 3. Character Occurrence Count (`str_count.java`)
Counts the number of occurrences of each character in the given string.

**Sample Output**
```text
Enter a string: banana
Character Occurrences:
b : 1
a : 3
n : 2
```

## How to Run

Make sure Java is installed. Open the terminal in the project folder and run the required program:

```bash
javac calculator.java
java calculator
```

Replace `calculator` with `str_validation` or `str_count` to run the other programs.

## Technologies Used
- Java
- Scanner class
- Conditional statements and loops
